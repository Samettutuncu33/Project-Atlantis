    How it works and what is assumed
    • A and C size to a 10% volatility target; at $200 that usually rounds below Saxo's 1,000-unit FX minimum, so they rarely trade. B and D trade the minimum ticket (far more risk).
    • E trades 20 instruments: FX, ETH/BTC, US stocks, indices, oil and gold. It predicts each one daily, learns which predictors work per asset class, and trades only when the expected edge beats costs.
    • Saxo costs: $1 minimum FX commission, 0.75% p.a. Tom/Next mark-up, 0.25% currency conversion, crypto funding 15% p.a. plus the 3.45% mark-up. CFD and minimum-size values are labelled assumptions until the Saxo API arrives.
    • Every run replays all accounts, reconciles them against an independent recomputation, and verifies that no earlier fill or prediction changed.
